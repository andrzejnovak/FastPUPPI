Summary: pixels help the tag, not the trigger

Pixel hits would triple the hardware-trigger b-tag efficiency, but the pixel readout chips cannot deliver them in time, and scouting the rejected crossings adds little even with perfect tags. The lever for low-mass HH→4b is a b-tagged L1 seed with the tracks already planned.
