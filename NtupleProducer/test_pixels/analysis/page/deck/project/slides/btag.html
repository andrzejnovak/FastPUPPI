II · Route A: pixels in L1 · b-tagging

6 / 15 (+13 backup)

Route A starts from a hypothesis: suppose the trigger could request pixel hits near its tracks within a few microseconds. Would that help? b hadrons live about 1.5 ps, so they fly a few millimetres before decaying; their decay tracks, extrapolated back, miss the collision point by the impact parameter d0, typically a few hundred microns. The hardware-trigger tracks are found in the outer tracker, which starts at 22 cm, so extrapolating them to the beam smears d0 by 545 microns (yellow). Adding hits from the pixel layers at 3 to 16 cm brings it to 35 microns (orange). Both are measured against the same particle reconstructed as a pixel-only track in the software trigger; that reference shares hits with the extended tracks, so 35 microns is a residual width, not a truth resolution. The baseline hardware b-tagger is a small neural network (NN) on 16 particles per jet using the outer-tracker tracks.
