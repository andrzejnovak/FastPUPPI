Per-jet b-tagging on L1 jets above 15 GeV: b jets from HH to 4b, light jets (not b, not c, including gluons) from QCD multijet events, both with 200 pileup collisions. Each “+” curve is a separately trained classifier on the NN scores plus the named features, trained on one half of the events and evaluated on the other. “HLT pixel tracks” are pixel-only tracks reconstructed in software after L1: a reference for how much the pixel information can give. The offline tagger uses other (offline) jets and is shown only for scale.
