If a future chip could read early: bandwidth

•

A request reads whole chips around the L1 jets

about 70 chips per crossing on average · 25–46 Gb/s in total, depending on the window size

•

Served before normal data: 1.9 µs median, 2.7 µs for 99%

real output links per module, normal readout at 750 kHz alongside, chip’s minimum 0.78 µs output delay included

•

Queued behind normal data: the slowest 1% wait 34 µs

normal readout already fills the busiest links to about 97% in this model: a future chip would need request priority

•

The CMSSW chip emulator overestimates the data volume

it writes charge bits for every pixel of a 4×4 core; counting hit pixels only gives 25–41% of its value (bug report pending)

•

Limits of the model

normal payload from 20 emulated crossings · no link framing · not an end-to-end latency budget
