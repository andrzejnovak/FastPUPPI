A better per-jet tag matters only if it changes which events the trigger accepts at an affordable rate. The seed: add up the b-scores of the four leading jets, require that sum and HT to pass thresholds, and choose the thresholds so the seed adds 2.5 kHz of background on top of the HT seeds (thresholds chosen on even-numbered events, efficiency measured on odd ones; measured added rates 2.3 kHz for the NN, 2.2 kHz for pixels). Then count the usable low-mass events kept: 60% with the HT seeds alone, 83% with the baseline NN scores, 96% with pixel scores, 99% with a perfect b-tag (generator flavour, an upper bound). Bars to scale, 0 to 100%. All four populations and the +15 kHz budget are in backup.
